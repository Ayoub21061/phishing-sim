⚠️ SIMULATION DE PHISHING

Vous venez de scanner un QR code piégé.

Pas de panique : cette page fait partie d'un exercice de sensibilisation autorisé par l'ECAM. Aucune de vos données n'a été volée. Mais si c'était une vraie attaque, elle le serait.

Ce QR code aurait pu se trouver n'importe où — une affiche, un sticker collé sur un mur, un faux avis sur une porte. En le scannant et en remplissant ce formulaire, vous auriez transmis vos informations personnelles à un inconnu.

Les bons réflexes :

  • Méfiez-vous des QR codes dans l'espace public, surtout ceux qui demandent des infos personnelles.
  • Vérifiez toujours l'adresse (URL) vers laquelle un QR code vous envoie avant de saisir quoi que ce soit.
  • L'ECAM ne vous demandera jamais vos données perso via un QR code affiché dans un couloir.
  • Dans le doute, ne remplissez rien et signalez-le.
🔒 Ce que cette page a réellement enregistré : uniquement votre matricule (pour le suivi de l'exercice) et, pour chaque autre champ, un simple « rempli / pas rempli ». Aucune valeur que vous avez tapée (adresse, téléphone, date de naissance) n'a été conservée.
